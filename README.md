# AquaScape

A calm top-down exploration game set in a Y2K / Frutiger Aero world. You play a small chrome explorer who travels across three connected areas, **Blue Lagoon → Glass City → Moonpool**, collecting bubbles and finding a Prism Shard in each area to relight its Aqua Beacon.

Made in Unity 6 (6000.6) with the URP 2D Renderer for CS 583 (Individual 2D Project).

## Controls

| Key | Action |
| --- | --- |
| WASD / Arrow keys | Move |
| Space | Aqua Pulse: open clams, power pylons, light beacons and lanterns, push glass cubes, repel jellyfish |
| Shift | Dash |
| Esc / P | Pause |

## How to play

1. Open the project in Unity 6000.6.
2. Open `Assets/AquaScape/Scenes/AquaScape.unity` and press Play.
3. To regenerate the scene from the level map, use **AquaScape → Build Level**.

## Project layout

| Path | What's there |
| --- | --- |
| `Assets/AquaScape/Scripts/` | Gameplay code (Core, Player, Gameplay, World, UI, Audio) |
| `Assets/AquaScape/Editor/` | One-click level builder, sprite importer, screenshot tool |
| `Assets/AquaScape/Level/level.txt` | The hand-designed ASCII map, generated by `Tools/LevelGen/level.py` |
| `Assets/AquaScape/Shaders/` | Water shader (shallows, foam, caustics, zone colours, horizon haze) and a particle shader |
| `Tools/ArtGen/` | Python scripts that render every sprite (an SDF "chrome / glass / ceramic" painter) |
| `Tools/AudioGen/` | Python scripts that synthesize all SFX and the adaptive music stems |
| `CHANGES_FROM_DESIGN.txt` | How the final game differs from the one-page design |
